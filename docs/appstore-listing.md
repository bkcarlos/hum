## 描述（≤4000）

```
Hum（哼一首）让你用一句话就能得到一份贴合心情的歌单。

不用费心搜索和拼凑——描述你的场景，比如“周日早晨的慵懒爵士”“跑步时的高能电子”“适合专注写代码的纯音乐”，Hum 会用 AI 理解你的意图，从 Apple Music 的真实曲库里挑出歌曲、给出推荐理由，让你边试听边勾选，满意了一键建成歌单存进你的资料库。

每一首都是 Apple Music 上真实存在的歌——不是 AI 编出来的歌名。

— 主要功能 —
• 自然语言挑歌：描述心情/场景，AI 解析并从真实曲库推荐
• 30 秒试听 + 完整播放：连接 Apple Music 后，订阅用户可完整播放
• 一键建歌单：勾选喜欢的，直接存进你的 Apple Music 资料库（私有）
• 对话式微调：“去掉有歌词的”“再活泼一点”，随时调整结果
• 删除学习：删掉不喜欢的，下次推荐会避开同类

— 两种使用方式 —
• 免费额度：用 Apple 登录即可使用，每日有一定推荐次数
• 自带 Key（BYOK）：填入你自己的大模型 API Key，不限量；Key 仅用于当次请求、绝不保存

— 关于隐私 —
你自带的 API Key 用完即弃，不会被存储或记录；Apple Music 凭证只保留在你的设备上。详见隐私政策。

需要 Apple Music 订阅才能完整播放与建歌单；未订阅时可试听 30 秒。
```

## App 隐私（营养标签）填写要点

- **收集且关联到身份**：邮箱地址（用途：App 功能 / 账号管理）、用户 ID（Apple `sub`）。
- **未收集**：自带 LLM Key（用完即弃，不申报）、位置、通讯录、浏览/搜索历史。
- 不用于追踪、不用于第三方广告。
